# Evidence

JSON files here are **operational metrics only**.

They must not contain:

- prompts
- model completions
- chain-of-thought
- customer data
- secrets
- hostnames or usernames

Eval-linked files are **EVAL_ONLY**. Do not train on the frozen cases in
`../eval/cases.json`.

Generated by:

- `scripts/collect_hardware.py` → `local-hardware.json`
- `scripts/run_smoke.py` → `local-deepseek-smoke.json`
- `scripts/benchmark_local_model.py` → `benchmark-baseline.json`
- `scripts/write_model_manifest.py` → `base-model-manifest.json`
